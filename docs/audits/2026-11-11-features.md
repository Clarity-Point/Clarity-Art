| ----------------------- | ------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------ |

| Передача организации    | Подтверждение паролем; преемник только из обычных участников своей организации | Неверный пароль, чужая организация, две передачи одновременно, свежие права старой сессии, выход прежнего администратора |

| Список сдач             | Поиск, фильтр статуса, курсорная пагинация, полные счётчики                    | Отдельные страницы, отсутствие дублей на неизменных данных, фильтры, недопустимый размер страницы                        |

| Редактирование дневника | Предупреждение при уходе с несохранёнными изменениями                          | Отмена перехода сохраняет текст, подтверждение позволяет уйти; очистка состояния при смене пользователя                  |

Сохраняется существующая система интерфейса. Убрана декоративная толстая боковая
рамка карточек терапевта; статусы остаются обозначены текстом и штатными значками.
Анимация полосы прогресса курса переведена с изменения ширины на transform.
Общая схема пагинации используется в уведомлениях и новых списках. Новых библиотек
и сервисов нет. Пароли, тексты работ и email не добавляются в аудит действий.

## Валидация

- `npm run check`: lint, форматирование, типы, 86 backend-тестов, 28 frontend-тестов,
  4 теста gate, production-сборки и отсутствие high/critical в проверке зависимостей.
- 31 Playwright-сценарий, включая 24 маршрута в двух темах и трёх ширинах;
  мобильная матрица использует широкий системный шрифт, выявивший прошлый сбой CI.
- Миграции применены к новой временной PostgreSQL 18.6; Prisma schema diff пуст.
- Гонки прав и модерации проверены настоящими HTTP-запросами и транзакциями PostgreSQL.
- Браузерные сценарии используют API-фикстуры, не рабочие аккаунты.

## Обновление и границы

Миграция `20261111010000_content_management` обязательна. Старые вкладки модерации
нужно обновить: отправка решения без версии теперь отклоняется. API списков сохраняет
формат массива, но больше не возвращает весь набор одним запросом — внешним клиентам
нужно следовать `X-Next-Cursor`. Подробные контракты и действия оператора описаны в
[инструкции по функциям](../operations/product-features.md).

Архив не ограничивает доступ к известному URL. Передача роли не меняет организацию
участников и не отзывает обычный вход: права проверяются по БД на каждом запросе.
Уже просмотренные терапевтом данные нельзя забрать из памяти человека или браузера;
отзыв согласия применяется к новым серверным запросам.

Рабочая инфраструктура, доставка реального SMTP, внешний AI, восстановление из
production-копии и нагрузка не проверялись. Для нескольких реплик по-прежнему нужны
общий каталог рисунков и общие лимиты. Не добавлены платные AI-функции, автоматические
внешние рассылки или удаление файлов-сирот без предварительной сверки. Эти задачи
требуют эксплуатационных данных и ограничений, которых текущий локальный проход
не подтверждает. Нагрузочные измерения поиска и автоматизация резервного копирования
остаются следующими техническими шагами; прогноз ускорения без измерений не делается.
