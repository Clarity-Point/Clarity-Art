# Производительность Clarity-Art на слабых устройствах

Задача охватывает загрузку интерфейса, работу холста, фоновые обновления и
подключение локального ИИ. Изменения сохраняют существующие упражнения, печать,
плеер, офлайн-ресурсы, историю и приватность черновика.

## Измеряемые узкие места

- Регистрация PWA предварительно кеширует весь опубликованный набор обложек.
  Шесть JPEG занимают около 1,4 МБ. Оптимизация заменяет только формат
  представления, сохраняя изображения и их размеры. WebP включается в тот же
  список офлайн-ресурсов вместе с музыкой.
- При восстановлении сессии профиль может отправить до 3 000 сообщений чата,
  хотя их использует только вкладка истории. Старые клиенты сохраняют прежний
  ответ `GET /api/profile`. Новый клиент для входа отправляет
  `GET /api/profile?view=summary`, а вкладка истории грузит прежний набор чатов
  по отдельному приватному маршруту `GET /api/profile/chat-history` с
  `X-Expected-User-Id`. Ответ остаётся ограниченным текущим числом сессий
  и сообщений. Отложенный ответ проверяется локальной версией аккаунта.
  Курсы, изображения, дневник и задания продолжают загружаться по их текущим
  контрактам. Вариант с пагинацией всех секций затронул бы их текущих потребителей.
- Холст повторно рисует путь при каждом движении и сканирует всю поверхность
  после каждого штриха. Рисовать только последний сегмент. Для цветного штриха
  проверять границы первого штриха на пустом холсте. Область очистки проверять
  при стирании. На тренировочном холсте сообщать о наличии рисунка, а PNG
  формировать при отправке черновика или скачивании. Пока штрих продолжается,
  отложить снимок. Ревизия черновика по-прежнему относится к зафиксированному
  снимку. После открытия изображения обновить признак пустого холста по его
  пикселям. Бумажное фото и его предпросмотр сохраняют прежний формат данных.
- Скрытая вкладка приостанавливает минутный опрос уведомлений. При возвращении
  счётчик немедленно обновляется. Открытие списка и ручные повторы продолжают
  загружать актуальное состояние.
- Браузеру и контейнерам Clarity-Art не требуется отдельная видеокарта.
  Локальные текстовые и визуальные модели выполняются в отдельном OpenAI-
  совместимом сервере. Дать контейнеру явный адрес хостового сервера на Linux и
  описать запуск Ollama с одной активной моделью и одним параллельным запросом
  для ограниченной памяти. Модель и контекст выбирает оператор. Приложение
  сохраняет текущие режимы локальной и внешней обработки. Ключи согласия и
  список данных, передаваемых провайдеру, остаются прежними.

## Приёмка

1. Сравнить производственную сборку и размер набора precache. Убедиться, что
   изображения и звук доступны после установки PWA, даже после отключения сети.
2. На синтетическом аккаунте с длинной историей сравнить байты полного и
   облегчённого ответа. Проверить отложенную загрузку истории, повтор после
   сетевой ошибки и очистку при смене аккаунта. Исключить чужие сообщения
   на уровне API.
3. Посчитать чтения пикселей и вызовы PNG на одинаковых штрихах в Chromium
   с программным рендерингом и замедлением CPU. Дополнительно проверить
   очистку, ластик, белую кисть, касание, скачивание и восстановление
   подтверждённого черновика.
4. Проверить оба Compose-файла, запуск приложения без ИИ и запрос к
   локальному совместимому серверу с синтетическим промптом. Фактическая
   скорость моделей зависит от выбранного runtime, RAM и видеопамяти.

Отдельная миграция БД не требуется. Для отката вернуть клиент и его сборку.
Старый клиент продолжит запрашивать полный профиль. Новый клиент при
отсутствии маршрута истории перечитает полный профиль с проверкой
аккаунта. Между версиями сохраняются серверные данные и офлайн-функции.

## Результаты локального прогона

| Сценарий                                            |        До |         После |
| --------------------------------------------------- | --------: | ------------: |
| Шесть обложек, байты                                | 1 427 120 |       607 158 |
| Набор ресурсов PWA, КиБ                             |  3 720,72 |      2 924,38 |
| JSON профиля с 3 000 синтетических сообщений, байты | 3 279 908 | 850 при входе |
| Пиксели, прочитанные для 30 цветных штрихов         | 9 720 000 |         3 240 |
| Кодирования PNG при рисовании 30 штрихов в демо     |        30 |             0 |
| Медиана времени обработки 30 штрихов, мс            |       521 |            18 |

Замер холста выполнен в пяти прогонах Chromium при выключенном GPU,
ширине 390 px и четырёхкратном замедлении CPU. Он измеряет время обработки
пакета событий, а не частоту кадров. Размеры JSON приведены до сжатия.
Отложенная история возвращает те же сообщения, что полный профиль.
После установки PWA без сети открылись шесть обложек и четыре звуковые
дорожки. Chromium прочитал метаданные записи без GPU. Подключение к локальному
ИИ проверено на тестовом OpenAI-совместимом сервере через обычный и потоковый API.
