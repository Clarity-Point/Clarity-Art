## Что это

Full-stack веб-приложение, где человек ведёт дневник, использует опционального
поддерживающего ИИ-собеседника, загружает или рисует изображение для
**рефлексивных** подсказок, проходит курсы с домашними заданиями и следит за
активностью через стрики, челленджи и таблицу лидеров. Есть ролевые кабинеты для
**терапевтов** (только при явном предоставлении доступа пользователем), админов
организации (privacy-protected групповые агрегаты) и админов платформы (управление
курсами).

Все ИИ-функции **опциональны и провайдер-агностичны** (см. ниже). Аналитические
«инсайты» — прозрачные эвристики на правилах, а не клинические оценки.

## Возможности

- **Дневник** — записи с календарём активности и опциональными неклиническими подсказками.
- **ИИ-чат** — опциональный поддерживающий собеседник со стримингом и историей сессий.
- **Рефлексия творчества** — загрузка или рисование на холсте для опциональных рефлексивных подсказок; не арт-диагностика.
- **Курсы** — программы арт-практик с модулями, уроками и домашними заданиями.
- **Практики** — дыхательные упражнения и плеер успокаивающего аудио (встроенные).
- **Прогресс** — активность, достижения, челленджи, лидерборд, галерея.
- **Safety notice** — консервативная проверка ключевых слов может показать ресурсы поддержки; это не crisis detection, triage или emergency care.

## Быстрый старт

Нужны **Node.js 22+** и **Docker** (для PostgreSQL).

```bash
npm install                       # ставит оба воркспейса
cp backend/.env.example backend/.env
cp frontend/.env.example frontend/.env

docker compose up -d db           # PostgreSQL (хост-порт 5433)
cd backend
npx prisma migrate deploy         # применить миграции
npx prisma generate               # сгенерировать Prisma Client
npm run prisma:seed               # курсы, достижения, демо-аккаунты
cd .. && npm start                # фронтенд :5173 + бэкенд :3100
```

Заполните `backend/.env` — обязательны только две переменные:

| Переменная     | Обязательна | Назначение                              |
| -------------- | ----------- | --------------------------------------- |
| `DATABASE_URL` | да          | строка подключения к PostgreSQL         |
| `JWT_SECRET`   | да          | секрет токенов — `openssl rand -hex 32` |

> Бэкенд **не стартует** без сильного, не-плейсхолдерного `JWT_SECRET`.
> Swagger (только dev): http://localhost:3100/api-docs.

## ИИ: опционально, локально, без привязки к вендору

ИИ-функции (чат, рефлексия творчества/профиля и опциональный текстовый safety signal) работают по
**OpenAI-совместимому протоколу `/chat/completions`**, поэтому подходит любой
такой сервер — в том числе полностью локальный. Укажите его в `backend/.env`:

```bash
AI_BASE_URL=http://localhost:11434/v1   # напр. Ollama / LM Studio / vLLM / LocalAI
AI_MODEL=llama3.1
AI_VISION_MODEL=llava                    # для анализа рисунков
# AI_API_KEY — оставьте пустым для локальных серверов без ключа
```

Если ИИ-провайдер **не** настроен, приложение всё равно работает от начала до
конца: ИИ-функции деградируют до заготовленных спокойных ответов. Обязательной
облачной зависимости нет, данные не обязаны покидать вашу машину.

## Тесты и проверки

```bash
npm run lint                                               # eslint (корень)
cd backend  && npm test && npx tsc --noEmit                # vitest + типы
cd frontend && npx vue-tsc --noEmit -p tsconfig.app.json   # типы фронтенда
cd frontend && npm run build                               # production-сборка
```


**отказывается запускаться** при `NODE_ENV=production`.
`node backend/prisma/enrich-demo.js` наполняет их данными для демонстрации.
